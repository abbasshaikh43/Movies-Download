Project: Anicare Movie Download Portal
A modern, responsive web portal for browsing and downloading the latest and trending movies, featuring:

Animated Navigation & Language Selector
A clean, top-fixed navbar with “HOME,” “MOVIES,” and “ABOUT US” links that slide into view, plus a dropdown to switch languages seamlessly.

Search Functionality
A custom search bar letting users quickly filter movie titles.

Dynamic Movie Listing
• New Releases & Trending Sections: Movie posters displayed as interactive cards.
• Download Buttons: One-click download triggers for each title.

Detail Modal with Carousel
Clicking a movie card opens a full-screen modal showcasing:

Large movie poster
Title and synopsis
“View Trailer” link
Prev/Next arrows to browse details without exiting
“Download” button

Engaging Hero Slider
At the top, a full-width carousel highlights featured blockbusters with left/right arrow controls for smooth transitions.

Contact & Footer
A simple footer with your contact number and email, reinforcing professionalism and making it easy for recruiters to reach out.
Tech & Animations
Vanilla HTML, CSS, and JavaScript
CSS3 keyframe animations for splash screens, modals, and sliders
Flexbox/Grid for responsive layouts
Clean, mobile-friendly design
